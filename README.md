📌 Project Overview

This project performs an in-depth Exploratory Data Analysis (EDA) on the United Nations Global Terrorism Analysis (UNGTA) dataset, covering over 180,000 terrorist incidents from 1970 to 2017.

The goal is to uncover meaningful insights, trends, and patterns in global terrorism using data analysis and visualization techniques.

🎯 Objectives
Analyze global terrorism trends over time
Identify most affected countries and regions
Examine attack types and weapon usage
Study casualty impact (killed & injured)
Generate insights for policymakers and researchers
❗ Problem Statement

Terrorism data is vast and complex, making it difficult to extract meaningful insights directly. This project applies structured EDA techniques to:

Clean and preprocess large datasets
Handle missing and inconsistent values
Analyze patterns across time, geography, and attack characteristics
Convert raw data into actionable insights
🛠️ Tech Stack
Python

NumPy – Numerical operations

4. Multivariate Analysis (M)

📈 Visualization Approach

This project follows the UBM Rule:

U (Univariate): Single variable analysis
B (Bivariate): Relationship between two variables
M (Multivariate): Multi-variable interaction
